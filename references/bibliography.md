# Bibliography

Background reading behind the `agent-factory` skill's design. These sources are **cited, not redistributed** — the skill needs the ideas, not copies of copyrighted files. Obtain each from its original publisher.

## Pseudocode / structured prompting (the core method)

- **"Prompting with Pseudo-Code Instructions"** — research paper making the case that pseudocode-structured instructions outperform natural-language prompts. Search arXiv for the title.
- **"3 Pseudocode Prompting Tricks to Get Better AI Responses"** — Jacynth, *AIBots* (Medium). Practical walkthrough of the same idea.

## Product / prompt-craft guidance

- **"Write great prompts for product work"** — Reforge. Role / decompose / constrain framing for PM-oriented prompting.
- **"Steal these prompts to ship better product"** — Reforge. Companion piece with reusable prompt patterns.
- **"Prompt engineering"** — OpenAI API documentation (`platform.openai.com/docs/guides/prompt-engineering`). Fundamentals: explicit instructions, sufficient context, structured output.

## Foundations

- **Chip Huyen, *AI Engineering: Building Applications with Foundation Models*** (O'Reilly Media, 2025). ISBN 978-1-098-16630-4. Foundational framing of prompt engineering within the broader AI-application stack. Buy it: <https://www.oreilly.com/library/view/ai-engineering/9781098166298/>
